# 实验5 微调线执行手册（微调线队员专用）

> **你的一句话任务**：教大模型做"解说词 → 动作分类"，交付三样东西：**100 条练习题（微调数据）→ 云端 LoRA 训练 → 微调前后对比表**。
> **背景**（3 句话，够用了）：实验5 是在实验4 的网页系统上加 AI 解说员（Agent 调工具）。微调是独立的加分线——**Agent 系统用原版大模型就能跑，不等你**，所以你按自己节奏做，但越早出数字，报告越好看。总计划见 `docs/TEAM_PLAN_EXP5.md`（可只读第三节 3.4）。
> 标签体系、预标工具全部现成（实验4 文本分类器），你主要做：抽样、核对、训练、跑分。

## 1. 造数据：练习题 100 条 + 考题 10 条（半天~1 天）

### 1.1 分类题 60 条（练习题主力）

**流程：脚本抽样 → 分类器预标 → 人工核对**（别纯手工也别纯 AI）。

1. **抽样**：写脚本从 `split_train.jsonl` 分层抽——10 个类别尽量每类都有，长短句混合；**跳过"其他"类**（模糊句没教学价值）。
2. **预标**：加载 joblib 分类器自动打标签：

```python
import joblib
clf = joblib.load("text_action_clf.joblib")
label = clf.predict(["库里外线出手，三分命中！"])[0]   # → '投篮'
```

3. **人工核对**：逐条看"这句话配这个标签对不对"，改掉错的，**记录改了几条**（写报告用）。
4. **标签纪律**：答案只能用 `train_text_clf.py` 开头注释里那 10 个类名，一个字都别改（不然和实验4 系统对不上）。

### 1.2 生成题 40 条（学解说风格，不进准确率评估）

**重要**：解说语料（直播吧 41 场）和 `events.csv`（MultiSports 视频）**不是同一批比赛，不能按时间对齐**。用"类别语义配对"：

- `input` = 合成的局面描述（动作类别 + 简单上下文），从 events.csv 的 action 列取真实动作类型；
- `output` = **真人解说原句**（用分类器预标选同类别语料）。

```json
{"instruction": "你是篮球解说员，根据场上局面写一句中文解说",
 "input": "事件：投篮（三分出手）；当前局面：第四节，比分胶着",
 "output": "顶弧再度发炮！这球要是进了就反超了！"}
```

抽查 5 条确认"事件类别 ↔ 解说句"语义相符即可，不必逐条精修。

### 1.3 考题 10 条（铁律：必须人工逐条确认答案）

从 `split_test.jsonl` 抽 10 条（覆盖 4~6 个类别），预标可以辅助，但**最终答案必须你自己看过确认**——这是给三个"考生"判分的标准答案，机器标的没资格当标准。

### 1.4 交卷前自检（写进脚本断言，别靠眼睛）

- [ ] 100 条 + 10 条，字段 `instruction/input/output` 齐全，JSON 能解析；
- [ ] **无泄漏**：10 道考题的原文一条都不许出现在 100 条练习题里；
- [ ] 分类题答案全部属于 10 类标签表；生成题 output 均为语料原句。

**产出**：`exp5/data/agent_finetune_data.json`（100 条）、`exp5/data/agent_eval_10.json`（10 条）、核对记录（预标改了几条，一句话存进 `exp5/data/build_notes.md`）。

## 2. 基线考试（训练前，本地半小时）

拿 10 道考题先考两个"没上过课的考生"，把数字存下来：

1. **大模型零样本**：用 OpenAI SDK 调（兼容端点，key 和地址问组长）：

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.chatanywhere.tech/v1", api_key="组长私发的key")
prompt = "判断这句篮球解说的动作类别，只从这10类里选一个作答：投篮/助攻传球/篮板/抢断/犯规违例/暂停换人/比分局势/阵容战术/防守/其他。\n解说：{text}"
resp = client.chat.completions.create(model="deepseek-v4.1-flash-1017", messages=[{"role":"user","content":prompt}])
```

（上面是组长已实测可用的组合：ChatAnywhere 中转 + DeepSeek-V4.1-Flash，正好是任务书示例模型；类名以 `train_text_clf.py` 为准。）
2. **joblib 分类器**：同 10 题跑一遍 predict。

**产出**：`exp5/eval/baseline.json`（记录：零样本对了几题、joblib 对了几题、每题模型答了什么）。

## 3. 上云训练（QLoRA，等待为主）

1. **平台**：Kaggle 或 Colab 任选（组里先例流程见 `docs/EXP3_KAGGLE_STEPS.md` / `docs/COLAB_STEPS.md`，开 T4 GPU 即可）。
2. **环境**：`pip install -U transformers peft trl accelerate bitsandbytes datasets`
3. **基座**：`Qwen3.5-1.7B-Instruct`（OOM 就降 0.5B，本手册参数都通用）。
4. **脚本** `exp5/train_lora.py` 核心配置（任务书点名的三件套都命中）：

```python
# 4-bit 量化加载（bitsandbytes）+ LoRA + 梯度累积 8 步
bnb_config = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4")
lora_config = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05,
                         target_modules=["q_proj","k_proj","v_proj","o_proj"])
TrainingArguments(per_device_train_batch_size=1, gradient_accumulation_steps=8,   # 任务书：梯度累积 8
                  num_train_epochs=3, learning_rate=2e-4, max_length=512,
                  gradient_checkpointing=True)   # 省显存，防 OOM
trainer = SFTTrainer(model=..., train_dataset=..., peft_config=lora_config)
```

5. **数据转换**：把 `instruction/input/output` 拼成对话模板（`user: instruction\ninput` / `assistant: output`），TRL 的 chat 模板或手动拼都行。
6. **预计耗时**：100 条 × 3 epoch，T4 上 10~20 分钟级别；挂后台跑，盯首尾即可。
7. **回传**：adapter 目录通常几十 MB，打包发组长（微信/网盘均可）。

**产出**：`exp5/train_lora.py`、adapter 权重包、训练 loss 曲线截图（报告用）。

## 6. 常见坑

1. **joblib 加载报 sklearn 版本警告**：装上 scikit-learn 即可，warning 可忽略（结果没错就不用管）。
2. **key 泄漏**：key 写 `.env` 或环境变量，**绝不写进代码、不截图发群、不提交 git**。
3. **Kaggle/Colab GPU 配额**：约 30h/周，够用，但跑完就关，别挂着空烧。
4. **OOM**：按顺序试——降基座 1.7B→0.5B → `max_length` 512→256 → 确认 `gradient_checkpointing=True`。
5. **生成题配对跑偏**：抽查"事件类别 ↔ 解说句"是否同义，配错就换句。
6. **Windows 编码**：脚本读写文件统一 `encoding="utf-8"`。
7. **防泄漏**：自检断言不过就重新抽，绝不放行。
