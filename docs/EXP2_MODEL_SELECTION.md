# 实验 2 模型对比实验设计（YOLO 系列内，训练后对比）

> 结论性对比**只在训练后进行**：所有模型在同一数据、同一超参（seed=42）下微调，
> 用 test 集 mAP / 推理速度说话。训练前不做任何"预训练零样本"类对比（已废弃）。
> 训练入口：`scripts/03_train/train_yolo.py`（Kaggle：`--run A1,A2,M1 --epochs 50 --patience 15 --device 0 --data-root /kaggle/input/<数据集名> --work-dir /kaggle/working`）。

> **执行状态（2026-10-22）**：实验报告实际执行核心 3 组 **A1/A2/M1**（Kaggle T4），
> B/C/D 未执行，保留为可选扩展。三组均已归档至 `models/exp2/A1_yolov8n/`、
> `A2_yolov8n/`、`A2_yolov8m/`（目录沿用 Kaggle notebook 命名，**A2_yolov8m 即 M1**）。
