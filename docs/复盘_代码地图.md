## 四、怎么跑起来

```
双击 start_exp5.bat   ← 后端 http://127.0.0.1:8000，前端 http://localhost:5173，Agent 页 /agent
双击 stop_exp5.bat    ← 一键停
```
（`exp4/complete_web_system/` 里另有一套自包含的 `start_project_v3.bat` / `stop_project.bat`，效果相同。）

> **本机（笔记本）注意**：这台机器没有 `backend\.venv`，上面两个 bat 起不来。
> 等价命令（用仓库根 `.venv`，三个终端各跑一条，2026-11-16 实测可用）：
> ```bash
> # ① API
> cd exp4/complete_web_system/backend && D:/Projects/python/basketball/.venv/Scripts/python.exe -u -m uvicorn app.main:app --host 127.0.0.1 --port 8000
> # ② Worker
> cd exp4/complete_web_system/backend && D:/Projects/python/basketball/.venv/Scripts/python.exe -u -m worker.main
> # ③ 前端
> cd exp4/complete_web_system/frontend && node node_modules/vite/bin/vite.js --host 127.0.0.1 --strictPort
> ```
> 配置在 `backend/.env`（不上 git）：`BASKETBALL_ACTION=on` 动作识别、`BASKETBALL_COMMENTARY=llm` 大模型解说（Worker 启动时读取）。
