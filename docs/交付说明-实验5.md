## 二、本机直接启动（已装好环境的情况）

双击 `代码/start_exp5.bat`（或把 bat 拷到仓库根目录双击）。

脚本会依次：检查端口 8000/5173 → 起后端 uvicorn → 轮询 `/api/v1/health` →
起前端 Vite → 轮询首页 → 打印模型自检 → 打开 `/agent` 页面。

停止：双击 `stop_exp5.bat`。

## 三、换一台机器怎么跑

1. 装 Python 3.12，创建虚拟环境：
   `py -3.12 -m venv exp4/complete_web_system/backend/.venv`
2. 安装依赖：
   `.venv\Scripts\pip install -r exp4/complete_web_system/backend/requirements.txt`
3. 前端依赖：`cd exp4/complete_web_system/frontend && pnpm install`（或 `npm install`）
4. 下载基座模型到 `models/Qwen3-1.7B`（HuggingFace `Qwen/Qwen3-1.7B`）；
   把 `模型/adapters-lora-8ep` 放到 `exp5/adapters/qwen3-1.7b-lora`。
5. 配置 `exp4/complete_web_system/backend/.env`（参考 `.env.example`）：
   `EXP5_LLM_BASE_URL / EXP5_LLM_API_KEY / EXP5_LLM_MODEL`。
6. 双击 `start_exp5.bat`。

## 五、已知限制（如实标注）

- Agent 依赖外网大模型 API（DeepSeek）；断网时走本地 LoRA 文本分类，但自然语言对话不可用；
- 基座模型不入包，缺它时 `/agent` 会报“AI 服务未就绪”，其余四个页面不受影响；
- 视频处理默认 `video_frame_step=2`，长视频端到端仍是数十秒级；
- 429 限流分支为注入验证，未在真实压测中触发。
