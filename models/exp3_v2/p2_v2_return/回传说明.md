## 口径红线
1. 交接包 §2 的 ultralytics 口径新基线（0.9920 / 0.7585 等）只用于确认权重身份，
   不得与本包 P2 自研评估器数字横比；同一 v1 A2 两把尺子相差约 1pp。
2. 本包对比只在 P2 评估器内部进行；表6 三列同权重同协议，避免混口径。
3. INT8 全套变体按交接说明未重跑；v2 E1 定位代价 2.19pp、v1 最优 1.58pp 均超 ≤1pp 门槛，
   「推荐 OpenVINO FP32」结论不变。
4. weights/a2v2_int8_val173.onnx 为本机按 v1 val173_pt 口径导出的等价产物（3.52MB），
   用于补齐实验四；该文件不在本回传包内，位于交付包 优化/weights/。
   若精度线有正式文件，原位覆盖同名文件即可。
